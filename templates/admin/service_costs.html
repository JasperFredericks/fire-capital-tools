About This Page

This page stores nothing. The static figures live in a config module in the codebase, so changing one is a commit with a reviewable history rather than an untracked form edit. The usual requirement that new storage use an env-var-overridable path pointing at the persistent volume is therefore not applicable here — there is no database, no file, and nothing to lose on a redeploy.

To correct a cost figure, edit tools/service_costs.py and bump its LAST_REVIEWED date. If keeping figures current without a deploy becomes genuinely useful, that is the point to add a stored, editable version — not before.

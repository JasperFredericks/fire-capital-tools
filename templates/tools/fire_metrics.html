How FIRE Score works
Preliminary market-screening score (0-100), percentile-based and relative to the current eligible tracked city universe.
Weights: Population growth 17%, Income growth 15%, Home-value growth 15%, Crime 11%, Employment growth 20%, Landlord friendliness 12%, Climate risk 10%.
Favorable direction: higher is better for population, income, home-value, and employment growth; lower is better for crime and climate risk.
Landlord friendliness maps directly: landlord-friendly = 100, neutral/mixed = 50, tenant-friendly = 0.
Missing-data rule: score publishes only with at least 70% weighted coverage, at least four components, at least one economic component, and at least one risk/operating component.
Coverage label reflects data coverage only (not statistical confidence). Rankings can change as source data or the comparison universe changes.
Crime metric used for v1: Not available.
This is a preliminary market-screening tool, not a property-level investment recommendation.

FBI Table 8 Crime Workbook Upload

Use this when the FBI publishes a new annual city-level crime workbook. Uploading the file only replaces the stored source workbook; the crime scores update the next time you run Refresh All Data.

Open FBI Crime Data Explorer
  1. Click "Documents & Downloads" in the top navigation menu.
  2. Scroll down until you see the section titled "Crime in the United States Annual Reports."
  3. In the first dropdown, select the most recent year available. Note: the newest year listed may not have this specific file ready yet — if downloading gives you an error or an empty/wrong file, try the previous year instead.
  4. In the second dropdown, select "Offenses Known to Law Enforcement." Do NOT select "Law Enforcement Employees Data" — that's a different dataset (police staffing numbers, not crime data).
  5. Click Download. This downloads a .zip file, not a ready-to-upload file yet.
  6. Extract the zip file — right-click it → "Extract All."
  7. Open the extracted folder. You'll see many files (Table 8, 9, 10, 11, etc.) — find and select only the one named starting with "CIUS_Table_8_Offenses_Known_to_Law_Enforcement..."
  8. Come back here, choose that file, and click "Upload Crime Workbook."
Don't rename the file, and don't open it and re-save it in Excel first — re-saving can silently change formatting the import depends on.

Source notes and methodology
Higher crime and climate risk scores are worse.
Landlord friendliness is an internal state-level score.
Job growth uses BLS LAUS resident employment, not physical job locations.
FEMA NRI is county-level and may not perfectly represent multi-county cities.
Some crime rows require manual review where agency/city matching is unreliable.
Each metric shows its own last-refreshed time — population/income/home value/employment/climate refresh live; crime index refreshes only after a FBI Table 8 workbook has been uploaded in Admin Data Tools.
